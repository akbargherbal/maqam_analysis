hashes, analysis evidence, maqam labels) for a private research dataset.

  transcriptions.

  MERT-v2-FullSong backbone are **CC-BY-NC-4.0** (non-commercial). Any derived
  artifact inherits that restriction.
- Keep this repository **private**. The backup script refuses to push to a
  public GitHub remote for this reason.
- The labels are weak, model-assisted readings, not ground truth, and must not
  be presented as definitive maqam attributions.
